# UI Guidelines

## Principles
- Consistent spacing, typography, and color tokens.
- Reuse shared components before creating feature-specific variants.
- Every screen should handle loading, error, empty, and content states.

## Shared Source
- Theme tokens: lib/core/theme
- Shared widgets: lib/core/widgets

## Required UX Baseline
- Forms include validation and clear feedback.
- Destructive actions require confirmation.
- Navigation flows should preserve expected back behavior.

## Accessibility
- Touch targets should remain comfortable for mobile usage.
- Keep contrast and readability suitable for production use.
