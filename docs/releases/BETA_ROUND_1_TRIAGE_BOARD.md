- Fix P0 and P1 immediately.
- Bundle P2 into next candidate.
- Move P3 to post-beta backlog.

## Daily Triage Cadence
- Morning: sort all new feedback by severity
- Midday: assign P0 and P1 owners and ETAs
- End of day: verify fixed blockers on device and update status

## Blocker SLA
- P0: start immediately, update every 2 hours
- P1: start same day, verify before next tester wave

## Ready For Beta Candidate 2 Checklist
- All P0 closed
- All P1 closed
- P2 candidate scope agreed
- Targeted tests rerun for fixed areas
- Full regression complete
- BC2 build and release notes prepared
